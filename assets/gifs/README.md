# 🧸 ASSETS / GIFS DIRECTORY GUIDE

Dito mo ilalagay ang iyong cute GIFs at animated pixel art!

### 📂 File Naming Conventions:
Ang website ay naka-setup na para i-load ang mga sumusunod na file:

1. **Landing Page GIF:**
   - File path: `assets/gifs/landing-couple.gif`
   - _Para sa cute couple animation o pixel bears sa unang page bago mag-YES o NO._

2. **Step 1 (Date & Time) GIF:**
   - File path: `assets/gifs/date-animation.gif`
   - _Para sa cute calendar o planning animation._

3. **Step 5 (Pickup Location) GIF:**
   - File path: `assets/gifs/pickup-animation.gif`
   - _Para sa pixel car o cute pickup animation._

4. **Final Page (Our Date Details) GIF:**
   - File path: `assets/gifs/final-couple.gif`
   - _Para sa romantic ending GIF kapag tapos na ang lahat ng steps._

---

### 💡 Paalala:
- **Suportadong Formats:** `.gif` (Animated GIF), `.png`, `.jpg`, `.jpeg`, `.webp`.
- **Kapag GIF:** Mananatili itong moving / animated at hindi magiging static.
- **Kung wala pang file:** Automatic na magpapakita ang website ng cute pixel placeholder frame na may instructions, kaya hindi masisira ang hitsura ng site habang naghahanap ka pa ng GIFs!
- **Palitan ang filenames:** Kung gusto mong gumamit ng ibang pangalan (halimbawa `assets/gifs/couple-bears.gif`), pwede mo lang palitan ang path sa [js/config.js](file:///c:/Users/edwin/Downloads/SCAM/js/config.js) o direkta sa `index.html`.
